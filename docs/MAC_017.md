# Mac Desktop 0.1.7 + Chrome Extension 0.3.1

12 ноября 2026. Сборка для Apple Silicon (ARM64).

Подключение из fizmat.win автоматическое: расширение достаточно включить, приложение запускается по koshirme:// после системного подтверждения Chrome. Ручных кодов, копирования, форм входа в комнату и кнопок переподключения в новых клиентах нет. Начало контеста и согласие остаются на сайте; macOS отдельно подтверждает закрытие пользовательских приложений.

Mac-контроль использует NSRunningApplication.terminate через подписанный Swift helper. Он оставляет Chrome, Коширме, Finder и системные/вспомогательные службы. Проверяются PID, путь bundle и время запуска, чтобы не закрыть другой процесс после повторного использования PID. Перед готовностью проверяется фактическое закрытие; отказ приложения, диалог сохранения или ошибка не считаются успехом. Повторное открытие проверяется каждые две секунды только при активном мониторинге. Пауза, завершение, отзыв, окончание lease и закрытие desktop отменяют незавершённые проверки. Принудительного завершения нет.

Сервер завершает индивидуальную попытку при закрытии одного из двух WebSocket-клиентов. Тихая потеря heartbeat обнаруживается примерно за 12–14 секунд после последнего сигнала любого клиента. Решения и баллы сохраняются; другой ученик и вся комната продолжают работу. После завершения переоткрытие приложения или новый билет не сбрасывают попытку. Начатая попытка не может быть заменена новым клиентом; исходный клиент может продолжить после серверного рестарта. Штатный перезапуск сервера закрывает сокеты с 1012 и оставляет окно на переподключение.

При отключении расширения desktop больше не пытается автоматически вернуть ученика в ту же попытку: он отключает мониторинг и закрывает свой серверный сокет. До начала экзамена отсоединение не завершает попытку.

## Проверки

- 13 сценариев Contabo: права, настоящие локальные HTTP/WebSocket, закрытие обоих клиентов, изоляция учеников, сохранение решений, heartbeat, защита от перезапуска и выхода из аккаунта.
- 43 теста Koshirme, включая четыре теста управления приложениями и завершение локального мониторинга при потере расширения.
- Нативная проверка на настоящих macOS GUI-приложениях: helper штатно закрыл тестовое приложение; второе тестовое приложение, имитирующее отказ из-за несохранённой работы, осталось открытым. Рабочие приложения пользователя не закрывались.
- Сборка включает подпись дополнительного native executable; распространение требует успешной Apple notarization и Gatekeeper.

Не путайте эти результаты с полным испытанием на ученическом рабочем месте с личными документами. Windows EXE этого выпуска не собирался. Chrome Web Store обновляется отдельно; ZIP 0.3.1 можно установить один раз в режиме разработчика до публикации в магазине.
