# Автоматический вход из Fizmat Contest

Обновлено 14 октября 2026: Fizmat и KOSH!RME опубликованы. Подписанный и нотарифицированный Mac DMG 0.1.6, ZIP расширения 0.3.0 и Windows source kit 0.1.6 доступны на koshirme.stream. Chrome Web Store уже показывает расширение 0.3.0 с датой обновления 13 октября. Windows EXE 0.1.6 требует сборки и проверки на Windows-ПК.

Проверка 14 октября выявила сбой SPA-перехода с главной страницы Fizmat по номеру: расширение 0.3.0 получало прежний URL документа и отклоняло мост. Исправление Fizmat с полноценным открытием адреса контеста, нормализацией старых ссылок и обновлением билета при задержке запуска Desktop опубликовано на fizmat.win 14 октября. Новая версия расширения не требуется. [Подробные результаты проверки](../../../FizmatContest/docs/AUTO_CONNECT_VERIFICATION.md).

Ученик открывает контест на fizmat.win. При включённом учителем мониторинге страница автоматически получает короткоживущий одноразовый билет, передаёт его расширению и открывает `koshirme://connect`. Приложение обменивает билет на сессию ученика; расширение подключается к localhost с тем же билетом. Ввод имени, номера комнаты и копирование pairing-кода не нужны.

После проверки приложения, расширения, сервера и разрешения на запись экрана страница показывает «Всё готово». Ученик подтверждает согласие и нажимает «Начать контест». Первое такое подтверждение автоматически запускает связанную комнату; пауза, установленная учителем, автоматически не снимается. Учитель видит ученика в существующей панели своего контеста. Время и доступность задач по-прежнему задаёт Fizmat Contest. Персональный таймер запускается после успешной проверки мониторинга на сервере.

Браузер может потребовать разрешение на открытие приложения либо заблокировать запуск без пользовательского действия. Через 8 секунд появляется ссылка повторного открытия, повтор подключения. Первичная установка расширения/приложения и разрешения ОС остаются обязательными. При отказе в запуске бесшовность ограничена политикой браузера; её нельзя обещать на всех компьютерах.

## Протокол и совместимость

- Билеты живут 120 секунд, хранятся на сервере только в виде хэша и потребляются атомарно. Проверяются действующий вход Fizmat, роль, доступ к контесту и включённый мониторинг.
- Ученики связываются по UUID аккаунта, а не по имени. Совпадающие имена не объединяются.
- Секрет интеграции и токен ученической сессии не передаются веб-странице. Расширение хранит website pairing только в `chrome.storage.session`.
- Мост принимает запросы только от верхней страницы `https://fizmat.win/contest/...` или `https://fizmat.win/contests/...`. Команда старта требует совпадения ученика/контеста и явного согласия.
- Перезапуск браузера может потребовать повторного открытия приложения. Уже согласованная сессия возобновляется по действующему токену без обнуления ready/active.
- Ручной вход в самостоятельные комнаты и старое подключение по 8-значному коду сохранены. Код больше не записывается в буфер при входе.

## Выпуск

Нужно выпускать согласованно:

1. Применить миграцию KOSH!RME `apps/cloudflare/migrations/0005_student_connect.sql`, затем обновить его Worker. Fizmat использует существующие Service Binding и приватный ключ, новых секретов нет.
2. Собрать, подписать и проверить на реальных Windows и macOS установщики Desktop 0.1.6 с обработчиком `koshirme://`. Опубликовать расширение 0.3.0 и обновить школьные компьютеры.
3. Опубликовать Fizmat вместе с его Worker, обновив ссылки загрузки на действительно опубликованные установщики. Публичные ссылки указывают на Mac 0.1.6 и комплект исходников Windows 0.1.6; ссылки на ещё не собранный Windows EXE нет.

Перед контестом с мониторингом обновите клиентские приложения: в monitored-контесте выдача задач, старт таймера и отправка решений теперь требуют готовой связанной сессии. Контесты без мониторинга работают прежним образом.

## Проверено локально

- Проверки типов всех пакетов; сборки Fizmat, панели, расширения и кода Electron; dry-run обоих Cloudflare Workers.
- Unit-тесты: одноразовость/истечение билетов, отзыв входа и доступа, изоляция одинаковых имён, возобновление сессии, автоматический запуск связанной комнаты с сохранением паузы, localhost pairing и согласие. Старые тесты жизненного цикла, возврата Chrome и захвата проходят.
- Реальный Chromium с расширением 0.3.0: автоматическое подключение, «Всё готово», согласие, запуск и обновление страницы. HTTP API и приложение в этом тесте — изолированные fixtures; запись реального экрана не выполнялась. Сценарий без расширения показывает инструкции и не открывает задачи.
- Четыре существующих браузерных теста Fizmat integration.spec.ts проходят.

## Проверка выпуска 13 октября

- Mac ARM64 0.1.6: codesign, spctl, нотарификация приложения и DMG, stapler, hdiutil verify прошли. Приложение запускается на Mac и корректно сообщает об отсутствующем разрешении записи экрана. Захват настоящего экрана не проверялся: разрешение ОС не предоставлялось.
- Production: оба сайта и health endpoints возвращают 200. ZIP расширения и исходников Windows скачаны и совпадают с локальными файлами. DMG доступен с ожидаемым размером.
- Изолированные тестовые аккаунты на production: создание связанной комнаты, одноразовый билет, передача нужной личности и комнаты, просмотр комнаты учителем, блокировка входа без живых клиентов. Тестовые записи удалены после проверки.
- Fizmat: 54 теста API/проверяющей системы, 4 существующих браузерных теста; отдельные проверки редактора, копирования примеров, мобильного интерфейса и отсутствия загрузки файлов/внешних ссылок у ученика с мониторингом.
- KOSH!RME: 38 тестов протокола, жизненного цикла, подключения и захвата. Реальный Windows smoke test остаётся необходимым после запуска Build-Windows.cmd.
