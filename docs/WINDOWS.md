# Windows: сборка KOSH!RME 0.1.6

Архив содержит исходники приложения, расширения и сценарии сборки полноценного установщика EXE. Windows EXE 0.1.6 нужно собрать и проверить на Windows 10/11 x64. Сборка на Mac не заменяет эту проверку.

## Подготовка

1. Установите Node.js x64 с npm, версия не ниже 22.12. Включите Add to PATH.
2. Распакуйте KOSHIRME-0.1.6-Windows-source.zip в отдельную папку, например C:\Koshirme. Внутри будет папка examguard.
3. Закройте запущенный KOSH!RME. Не переносите node_modules с Mac.
4. Для сборки нужен интернет. Python, Docker и локальная база данных не нужны.

## Собрать EXE

Откройте файл **Build-Windows.cmd** в папке examguard. Он запускает PowerShell только для этого процесса, устанавливает зависимости по package-lock.json, проверяет типы и тесты и собирает установщик.

Или выполните в PowerShell из папки examguard:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\apps\student-desktop\scripts\build-windows.ps1
```

Результаты находятся в apps/student-desktop/release:

- KOSHIRME-0.1.6-x64.exe — установщик приложения.
- KOSHIRME-0.1.6-x64.exe.sha256 — контрольная сумма.
- koshirme-chrome-extension-0.3.0.zip — расширение Chrome.
- koshirme-chrome-extension-0.3.0.zip.sha256 — контрольная сумма.

Без настроенного сертификата Windows EXE будет без Authenticode-подписи. Не выдавайте исходный ZIP за готовый установщик.

## Проверка на Windows

1. Установите EXE. Установщик регистрирует ссылку koshirme:// для запуска из браузера.
2. Установите расширение 0.3.0 или новее. Версия 0.2.9 поддерживает прежний ручной вход, но не автоматическое подключение Fizmat. Пока 0.3.0 не опубликована в магазине, для теста распакуйте ZIP и выберите chrome://extensions → Режим разработчика → Загрузить распакованное расширение. Отключите другую копию KOSH!RME в этом профиле.
3. Учитель включает мониторинг в отдельном тестовом контесте fizmat.win. Ученик входит в свой аккаунт и открывает контест.
4. Подтвердите открытие приложения в Chrome. Имя, комната и связь с расширением передаются автоматически. Копировать код не нужно.
5. На странице должно появиться «Всё готово». Дайте согласие на мониторинг и нажмите «Начать контест». Учитель должен видеть ученика в мониторинге того же контеста.
6. Проверьте перезагрузку страницы, восстановление соединения, паузу, продолжение и завершение. После завершения блокировки должны сниматься.
7. В тестовой комнате проверьте переключение вкладки и возврат к контесту. Для проверки снимков используйте тестовый рабочий стол без личных данных.
8. Проверьте повторный вход с другой сессии: учитель разрешает вход, запрос исчезает, ученик может войти снова.

Для независимой комнаты на koshirme.stream сохранён ручной вход по коду. Автоматический вход используется в контестах Fizmat.

## Если сборка не проходит

- Node не найден: переустановите Node x64 с npm и PATH, затем откройте новое окно терминала.
- EPERM или занятый Electron: закройте процессы этого проекта и повторите сборку.
- Не скачивается Electron или NSIS: проверьте интернет и прокси.
- Приложение не открывается из браузера: установите EXE, а не только запустите исходники.
- Нет связи: проверьте версии, одну копию расширения и один Desktop.

После проверки EXE можно загрузить владельцу в существующий bucket examguard-downloads. Ссылку на установщик на сайте следует обновлять только после загрузки и проверки файла. Текущий комплект не публикует непроверенный Windows EXE автоматически.
