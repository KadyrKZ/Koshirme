# Задание для Codex на Windows

Ты работаешь на реальном ученическом Windows 10/11 x64 ПК. Создай ветку windows/desktop-exam-mode.
Реализуй в desktop экзаменационный режим: перед готовностью закрыть остальные пользовательские приложения, кроме явно необходимых исключений; во время активного экзамена обнаруживать повторный запуск и штатно закрывать запрещённые приложения. Предупреждение и согласие ученика до первого закрытия обязательны. Проверяй реальное закрытие, а не только отправку команды. До старта, при паузе и после завершения не закрывай приложения. Учитывай несколько окон, дочерние процессы, приложения с несохранённой работой и разные уровни прав. Если текущих прав недостаточно, покажи конкретное ограничение; не обещай полную системную изоляцию.

Работай до завершения задачи. Серверы для испытаний: https://fizmat.win и https://koshirme.stream. Не заменяй физическое испытание моками, localhost или протокольной имитацией. Автотесты — дополнительная проверка.
Прочитай README.md, docs/AUTO_CONNECT.md, docs/WINDOWS.md и исходники apps/student-desktop/src/services/{guard,backend,chrome-browser,local-server}.ts. Если открыт общий репозиторий, desktop находится в anti/examguard, сайт в FizmatContest; команды npm выполняй из соответствующего проекта.
До любого изменения apps/chrome-extension заранее сообщи пользователю, какие файлы и зачем меняешь. Сайт и desktop сами не обновляют установленное расширение. Не публикуй непроверенную сборку и не меняй production-сервер без отдельной необходимости.
Работай на тестовом рабочем столе без личных данных. Для закрытия приложений сначала предупреди сохранить работу; используй штатное закрытие окон. Не завершай системные процессы, средства доступности, Chrome, Коширме и необходимые сетевые службы. При отказе приложения закрыться или диалоге сохранения покажи причину и не объявляй готовность экзамена. Не используй массовый taskkill /F, kill -9, отключение антивируса или обход защиты ОС. Список исключений обоснуй и покажи пользователю.
Нужны отдельные тестовые аккаунты учителя и ученика и отдельный тестовый контест с мониторингом на реальном сайте. Если их нет, попроси пользователя войти/предоставить тестовые аккаунты; не копируй чужие сессии. Записывай время, версии ОС/Chrome/desktop/расширения, git SHA, room/contest ID, результаты каждого шага, доказательства в панели учителя. Токены, cookies, пароли и личные скриншоты не коммить.
Проверь: запуск установленного desktop по koshirme:// из реального ученического кабинета; автоматическую связь с установленным расширением без ручной подмены; совпадение ученика/комнаты в панели; оба живых клиента; готовность и запуск; отправку решения и настоящий вердикт; другую вкладку, другое приложение и закрытие Chrome; появление нарушения и снимка у учителя; разрыв сети и восстановление; Pause/Resume/Finish и отзыв доступа. После Finish/Pause не должны продолжаться закрытие приложений и принудительное восстановление Chrome. Проверь повторный вход и отсутствие дублей комнат/учеников.
Напиши отчёт docs/verification/PLATFORM-REAL-SERVER.md с таблицей PASS/FAIL/BLOCKED, точными версиями и ссылками на обезличенные доказательства. Не выдавай автоматические тесты или сборку за физический PASS. Исправь обнаруженные ошибки и повтори затронутые сценарии. Изменения коммить в отдельную ветку без force push, не затрагивай параллельную платформенную ветку.

Подготовка: из anti/examguard выполни powershell -NoProfile -File scripts/prepare-native-check.ps1. Затем собери EXE штатным Build-Windows.cmd, установи и тестируй установленное приложение, а не dev-процесс. Расширение используй установленное из Chrome Web Store; проверь его фактическую версию. Для изменения расширения сначала предупреди пользователя.
Отдельно проверь Блокнот с сохранённым и несохранённым текстом, Калькулятор и повторное открытие программы во время экзамена. Сохрани результат каждого случая. Не трогай открытые реальные работы ученика.
В отчёте замени PLATFORM на WINDOWS.
