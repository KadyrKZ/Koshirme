# Проверка приложений Windows

Начиная с Desktop 0.1.8 проверку выполняет `koshirme-app-guard.exe`, который собирается из `apps/student-desktop/native/windows-app-guard.cs` и поставляется вместе с приложением. Сборка Windows включает помощник в проверку Authenticode.

Помощник перечисляет видимые окна и проверяет PID, сеанс Windows, владельца, путь к EXE и время запуска процесса. Для закрытия проверенного окна используется штатный `WM_CLOSE`. Отказ в доступе к отдельному процессу фиксируется в журнале. Если процесс с видимым окном не удаётся проверить и исключить по правилам Коширме, он блокирует старт. Диалог несохранённой работы может потребовать ручного закрытия.

Доступ к экрану проверяется при открытии Desktop. Подтверждение закрытия приложений запрашивается перед запуском контеста. Активная сессия, проверку которой невозможно продолжать, теряет готовность и соединение с сервером.

Шаги для школьного ПК, журнал и разбор сбоя PowerShell 0.1.7 находятся в [инструкции Windows](WINDOWS.md).
