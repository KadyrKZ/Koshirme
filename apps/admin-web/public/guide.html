Обновлено 13 октября 2026. Desktop 0.1.6 · Chrome 0.3.0.

Контест на fizmat.win

  1. Учитель включает мониторинг в настройках контеста.
  2. На компьютере ученика установлены приложение 0.1.6 и расширение 0.3.0 или новее.
  3. Ученик входит на fizmat.win и открывает контест. Chrome может попросить подтвердить запуск приложения.
  4. Приложение и расширение подключаются автоматически. Имя и комната передаются из аккаунта; копировать коды не нужно.
  5. Когда появится «Всё готово», ученик даёт согласие на мониторинг и нажимает «Начать контест». Учитель видит подключение в панели этого контеста.

На Mac разрешите запись экрана для Коширме в системных настройках и перезапустите приложение, если оно запросит это разрешение.

Установка

  • macOS Apple Silicon: подписанный и проверенный Apple DMG 0.1.6
  • Windows: комплект для сборки EXE 0.1.6 на Windows-ПК. Новый Windows EXE ещё требует сборки и проверки на Windows.
  • Коширме в Chrome Web Store
  • Расширение 0.3.0 для проверки и ручной установки

Проверьте версию расширения в chrome://extensions. Опубликованная 0.2.9 работает с ручным подключением; автоматическое подключение требует 0.3.0. Пока обновление не доступно в магазине, распакуйте ZIP и используйте «Режим разработчика → Загрузить распакованное расширение». Отключите прежнюю копию в этом профиле, чтобы не запускать две одновременно.

Учителю

Откройте мониторинг в нужном контесте. Здесь видны ученики и их состояние. Пауза приостанавливает мониторинг, завершение снимает ограничения. Проверьте работу на одном тестовом аккаунте перед уроком. Учитель своего контеста может разрешить повторный вход ученику; обработанный запрос исчезает из очереди.

Отдельная комната

Для комнат, созданных непосредственно на koshirme.stream, сохранён прежний ручной сценарий: код комнаты в приложении, сопряжение расширения, согласие ученика и запуск учителем.

Если подключение не получилось

Проверьте версии приложения и расширения, разрешение записи экрана, интернет и подтверждение запуска в Chrome. На странице контеста используйте «Повторить подключение». Если открыт другой контест с мониторингом, сначала завершите его.
